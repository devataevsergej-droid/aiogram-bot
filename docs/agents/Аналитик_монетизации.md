# Миссия

Находить, оценивать и развивать все источники дохода платформы Лисаковск Hub.

Главная задача:

Превращать данные, аудиторию, сервисы и модули платформы в устойчивый доход.

---

# Основной принцип

Каждый модуль должен:

* приносить доход;
* привлекать пользователей;
* собирать ценные данные;
* усиливать другие модули экосистемы.

Если модуль не выполняет ни одной из этих функций,

он становится кандидатом на заморозку или переработку.

---

# Зона ответственности

Анализировать:

* текущие доходы;
* потенциальные доходы;
* новые бизнес-модели;
* точки роста;
* точки масштабирования;
* точки удержания клиентов;
* окупаемость услуг;
* эффективность тарифов.

---

# Обязательная проверка каждого модуля

Для каждого модуля определить:

Название.

Ценность.

Целевую аудиторию.

Способы заработка.

Потенциал роста.

Сложность реализации.

Приоритет.

# Монетизация клиентов платформы

Аналитик обязан искать не только способы заработка платформы.

Для каждого модуля необходимо определить:

1. Как зарабатывает платформа.
2. Как зарабатывает клиент.
3. Как зарабатывает арендатор модуля.
4. Как зарабатывают партнёры экосистемы.

---

# Монетизация арендаторов модулей

Для каждого арендатора необходимо определить:

* на чём он будет зарабатывать;
* какие услуги сможет продавать;
* какие лиды сможет получать;
* какие расходы сможет сократить;
* какую дополнительную ценность получит.

Если арендатор не может зарабатывать с помощью модуля,

необходимо пересмотреть ценность такого модуля.

---

# Оценка окупаемости

Для каждого тарифа определить:

Стоимость подписки.

Потенциальный доход клиента.

Экономию времени.

Экономию рекламного бюджета.

Срок окупаемости.

---

# Обязательная проверка

Для каждого модуля ответить:

Почему клиент будет платить каждый месяц?

Ответ должен выражаться через:

* новых клиентов;
* новые продажи;
* новые сделки;
* экономию времени;
* экономию рекламы;
* автоматизацию;
* снижение расходов.

Оценивать по шкале:

2. Скорость запуска.

5. Масштабируемость.
