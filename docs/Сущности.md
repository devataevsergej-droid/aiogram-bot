# Назначение документа

Документ определяет основные сущности платформы Лисаковск Hub.

Все новые модули обязаны использовать существующие сущности платформы перед созданием новых.

Создание новой сущности допускается только при наличии новой бизнес-концепции.

---

# Базовые сущности платформы

Это сущности, принадлежащие всей экосистеме и доступные нескольким модулям одновременно.

---

# Hub

Отдельная городская экосистема внутри платформы.

Примеры:

* Лисаковск Hub
* Рудный Hub
* Костанай Hub

Основной идентификатор:

```text
hub_id
```

Статус:

IMPLEMENTED (архитектурно)

---

# User

Глобальный пользователь платформы.

Создаётся один раз.

Может использовать несколько модулей одновременно.

Может иметь несколько ролей.

Примеры:

* житель;
* соискатель;
* работодатель;
* предприниматель;
* организатор.

Основной идентификатор:

```text
user_id
```

Источник истины:

Core

# Архитектурное правило

Новая сущность создаётся только тогда,

когда появляется новая бизнес-концепция.

Запрещено создавать отдельную сущность для каждой новой функции.

Пример:

```text
Работодатель

=

User + Role
```

а не отдельная таблица работодателей.

---

# Принцип экосистемы

Все сущности должны стремиться к повторному использованию между модулями.

Если сущность может использоваться несколькими модулями,

она должна находиться в Core.

Если сущность относится только к одному модулю,

она может находиться внутри соответствующего модуля.

---

# Принцип данных

Каждая сущность должна отвечать на три вопроса:

1. Какие данные хранит?
2. Кто владелец данных?
3. Какие другие сущности используют эти данные?

Если ответы отсутствуют,

структура сущности требует пересмотра.
