# Бот «Работа Лисаковск»

Telegram-бот на `aiogram 3` + Supabase для двух сценариев:

- **Ищу работу** — соискатель заполняет мини-анкету и получает подходящие вакансии.
- **Ищу сотрудника** — работодатель отправляет вакансию на модерацию, после одобрения она публикуется в канал и рассылается подходящим соискателям.

Первый контакт анонимный: контакты работодателя видны в публичной вакансии после модерации, контакты соискателя уходят работодателю только после нажатия «Откликнуться».

## Быстрый старт

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
cp .env.example .env
python -m job_lisakovsk_bot.main
```

Перед запуском примените SQL из `db/schema.sql` в Supabase и заполните переменные окружения.

## Возможности

- FSM-анкета соискателя и FSM-размещение вакансии.
- Модерация вакансий в админ-чате.
- Публикация одобренных вакансий в `CHANNEL_ID`.
- Рассылка подходящим соискателям по сфере и графику с лимитом бесплатного тарифа.
- Telegram Stars: безлимит вакансий, закреп, срочная рассылка, VIP соискателя.
- Ручная оплата на баланс Билайн с подтверждением админом.
- Реферальные deep-link ссылки и бонусы за друзей.
- Личный кабинет `/my_stats`, админ-статистика `/admin_stats`.
- APScheduler: ежедневный/ежемесячный сброс лимитов, снятие закрепа, недельная статистика в канал.
- Health-check `/` и `/health` для Cron-job.org/UptimeRobot/Render.

## Переменные окружения

См. `.env.example`.

## Основные команды

- `/start` — главное меню.
- `/start resume` — сразу открыть анкету соискателя.
- `/start vacancy` — сразу открыть создание вакансии.
- `/start ref_USER_ID` — учесть реферальный переход.
- `/vacancies` — посмотреть активные вакансии.
- `/invite` — получить реферальную ссылку.
- `/my_stats` — личный кабинет.
- `/admin_stats` — админ-дашборд в админ-чате.

## Render и стучалка

Приложение поднимает HTTP health-check на `PORT` и отвечает `OK` на `/` и `/health`. Для Render задайте `WEBHOOK_URL=https://lisakovsk-job-bot.onrender.com/webhook`: тогда бот сам установит webhook и будет принимать Telegram updates на `/webhook`. Подробный чеклист деплоя — в `DEPLOY.md`.
